# Projeto Prático Interdisciplinar I

## Bella Tavola - Restaurante Italiano

Projeto desenvolvido para a disciplina Projeto Prático Interdisciplinar I - Desafio 02.

## Sobre o projeto

O projeto consiste no desenvolvimento de uma página web para um restaurante fictício chamado Bella Tavola.

A página apresenta três categorias de pratos:

- Entradas
- Pratos Principais
- Sobremesas

Cada prato possui nome, descrição, preço e imagem.

## Tecnologias utilizadas

- HTML5
- CSS3

## Arquivos do projeto

- `index.html` - página inicial do projeto.
- `menu.html` - página do menu do restaurante.
- `style.css` - arquivo responsável pela estilização da página.

## Site publicado

O projeto está disponível no GitHub Pages.
