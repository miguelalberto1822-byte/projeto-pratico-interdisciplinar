### Diferença entre Git e GitHub

O Git é um sistema de controle de versão distribuído utilizado para acompanhar e registrar alterações realizadas em arquivos e projetos.

O GitHub é uma plataforma de hospedagem e colaboração de projetos que utiliza o Git, permitindo armazenar, compartilhar e colaborar no desenvolvimento de códigos.

### Alternativas ao GitHub

Algumas plataformas alternativas ao GitHub são:

- GitLab
- Bitbucket
- Codeberg

## Parte II - Desenvolvimento do site

O projeto consiste no desenvolvimento de uma página web para um restaurante fictício chamado Bella Tavola.

A página apresenta três categorias de pratos:

- Entradas
- Pratos Principais
- Sobremesas

Cada prato possui nome, descrição, preço e imagem.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estrutura do projeto

- `index.html` - página inicial que direciona para o menu.
- `menu.html` - página principal do restaurante.
- `style.css` - arquivo responsável pela estilização da página.
- `README.md` - documentação do projeto.
